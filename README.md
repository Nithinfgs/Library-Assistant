## 🌟 Key Features

### 🎓 Student Hub & Portals
- **Academic & DP Subject Catalog**: Coursebooks, lab practical guides, and exam study materials for Chemistry, Physics, Biology, Mathematics AA HL, and Computer Science.
- **Fiction & Non-Fiction Lounge**: Fantasy sagas (Percy Jackson Books 1–5, Heroes of Olympus), science fiction classics (Dune, 1984), and literary collections.
- **Reading Journey Tracker**: Log study and reading sessions, record milestones and deadlines, track countdowns, and celebrate completed books with confetti animations.
- **My Loans & Waitlists**: Instant view of active borrowed titles, real-time waitlist reservation positions (#1, #2), and book requisition requests.
- **1-Click Dev Fast Login**: Instant seamless persona testing (`Dev Student` & `Dev Librarian`).
- **Mac Trackpad Swipe Navigation**: Native browser history and two-finger swipe back/forward support.

### 🛡️ Librarian / Staff Console
- **Live Circulation & Overdue Tracking**: Real-time due date monitoring with automated overdue notices and past-due duration tracking.
- **Book Catalog & Inventory Control**: Real-time copy availability, aisle/shelf/floor locations, and custom book entry additions.
- **Auto-Promoting Waitlists**: Returning a book automatically dispatches a pickup notification and promotes the next waiting student in queue.
- **CSV Data Exports**: One-click full catalog CSV export and detailed shared/borrowed records export with student names, grades, and loan statuses.
- **Condition & Damage Logging**: Catalog damage and loss reporting with condition tags (Good, Minor Wear, Spine Damaged, Water Stained, Missing).

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite + TypeScript
- **Styling**: Tailwind CSS + Custom Design System
- **Animations**: Framer Motion (Spring Physics & Staggered Ensembles)
- **Icons**: Lucide React
- **Celebrations**: Canvas Confetti
- **Deployment**: Netlify

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/Nithinfgs/Library-Assistant.git

# Navigate into project directory
cd Library-Assistant

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
